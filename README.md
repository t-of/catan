# catan — 1台で交代して遊ぶ陣取りボード

六角タイルの盤で資源を集め、道・開拓地・都市を建てて競う交代プレイの試作。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/catan/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

カタン基本セットのルールで、3〜6人が1台の画面を回して交代で遊びます。席ごとに「人」か「CPU」（よわい・ふつう・つよい）を選べ、人が1人だけでも遊べます。

- 5人・6人を選ぶと、公式の5〜6人拡張の盤（30マス・港11か所）に自動で変わります。銀行の資源は24枚ずつ、発展カードは34枚になります。
- 5〜6人では、誰かの手番が終わるたびに「特別建設フェイズ」が入ります。手番を終えた人以外が順番に、道・開拓地・都市を建てる／発展カードを買うことだけできます（交易や発展カードを使うのは不可）。建てなければ「パス」で次の人に回ります。
- 3〜4人では、はじめる前に拡張を「なし」か「航海者版」から選べます（5〜6人拡張との組み合わせはありません）。
  - 航海者版は、本島（3〜4人用と同じ19マス）を海で囲み、その外に小島が3つ（各2マス）浮かぶ盤になります。金の川（金鉱）マスは、出目が合えば好きな資源を1枚ずつ選べます（CPUは足りない資源を選びます）。
  - 船は木1・羊1で、海に面した辺で自分の開拓地・都市か自分の船につながる場所に置けます。手番に1回だけ、列の端にある船（置いたばかりでないもの）を別の海の辺へ動かせます。
  - 7や騎士を使うと、盗賊の代わりに海賊を海マスへ動かせます。海賊の隣の辺には船を置けず・動かせず、隣に船がある人から1枚奪います。
  - 小島に初めて開拓地を建てると+2点のボーナスがあります。勝利点は14点、船の上限は15隻、発展カード「街道建設」は道・船どちらでも2本まで建てられます。道・船どちらにも置ける海沿いの辺をタップすると、窓でどちらにするか選べます。
  - CPU（よわい・ふつう・つよい）も船を建てて小島まで進み、最後まで遊べます。7や騎士で盗賊の代わりに海賊を動かしたほうが得なときは、CPU（よわいを除く）も海賊を動かします。
- 最初に開拓地と道を2個ずつ置きます（1周目は順番、2周目は逆順）。
- 手番: サイコロを振る → 出た目の資源をもらう → 道・開拓地・都市・発展カードを建てる/交易する → 手番を終わる。
- 7が出たら、手札8枚以上の人は半分捨て、盗賊を動かして隣の1人から1枚奪います。
- 交易は銀行・港（3:1 か 2:1）のほか、相手を選んで出す・もらう資源を決める簡単な形です。相手がCPUのときは、その場の内容が得かどうかでCPUが受ける・断るを決めます。
- 得点が10点に届いたら勝ちです（開拓地1点・都市2点・最長交易路+2点・最大騎士力+2点・勝利点カード1点）。
- 盤面をタップして開拓地・道・都市・盗賊の場所を選びます。下のボタンでサイコロ・建設・交易・発展カード・手番終わりを操作します。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
