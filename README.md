# catan — 1台で交代して遊ぶ陣取りボード

六角タイルの盤で資源を集め、道・開拓地・都市を建てて競う交代プレイの試作。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/catan/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

カタン基本セットのルールで、3〜4人が1台の画面を回して交代で遊びます（CPUなし）。

- 最初に開拓地と道を2個ずつ置きます（1周目は順番、2周目は逆順）。
- 手番: サイコロを振る → 出た目の資源をもらう → 道・開拓地・都市・発展カードを建てる/交易する → 手番を終わる。
- 7が出たら、手札8枚以上の人は半分捨て、盗賊を動かして隣の1人から1枚奪います。
- 交易は銀行・港（3:1 か 2:1）のほか、相手を選んで出す・もらう資源を決める簡単な形です。
- 得点が10点に届いたら勝ちです（開拓地1点・都市2点・最長交易路+2点・最大騎士力+2点・勝利点カード1点）。
- 盤面をタップして開拓地・道・都市・盗賊の場所を選びます。下のボタンでサイコロ・建設・交易・発展カード・手番終わりを操作します。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
